# Rising Causeway — primary assessment

Decision: keep the existing L4/Full baseline and implemented ladder provisionally; do not accept the review's proposed profile revision solely because L5 lacks a new planning stage. The parent read the complete controls, generator, JavaScript/CSS, grader, task verifier, solver and task/environment specifications, and visually inspected the wrong-stair and corrected-stair renders from the recovery diagnostic.

The stair-choice concern omits an existing recovery path. `activateStair` permits switching the selected end before traversal; clicking an end is not an irreversible commitment. In separate D4/Full and D4/Simplified seed-1 browser runs, the parent first selected LEFT (the wrong answer), then the unchanged solver selected RIGHT and completed the same challenge. Server, direct grader and exported verifier all passed. The captured Full wrong selection shows a high leading face; the corrected selection shows a rising sequence toward the launch terrace. A player can inspect the effect before walking onto it. This does not establish human cue reliability, but it refutes treating a uniquely readable pre-selection answer or newly added recovery as necessary. See browser lines 202–217 and 457–464, and the `rising_reconfigure_diagnostic` browser records.

The L4→L5 change includes a fourth actionable launcher, a narrower support corridor, a smaller terminal reach radius, and taller steps. These are actual spatial-choice and motor-control changes, even with the same three red extensions. Difficulty need not add a new planning dependency at each level. Conversely, extra red clicks, longer traversal and lower speed are not independently sufficient evidence for a higher label. Neither source comparison nor passing the privileged oracle proves calibrated L5 placement.

The review is correct that question-mark decoys are noninteractive clutter. Count their potential visual search effect, not extra actuator decisions. It is also correct that D2 requires a wall launcher while D3 can select a floor launcher, so adjacent-level ordering is not demonstrated uniformly across seeds. This warrants a measured distributional comparison, not an automatic relabel from parameter counts.

The worlds and replay physics are shared across interaction modes; the different look/movement/actuator input sources are bound by the grader. Inspectable browser geometry is consistent with the project's static-runtime boundary. No puzzle sources or labels were changed.
