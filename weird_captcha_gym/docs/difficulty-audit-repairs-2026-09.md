# September difficulty-audit repairs

Status: implementation repairs and automated checks complete; calibration gates remain separate. The user authorized repairs and end-to-end privileged-information solutions after the [49-environment source audit](../difficulty_audits/REPORT.md). The original audit and its failed records are historical evidence and remain unchanged.

## Acceptance contract

The oracle may read generated truth, inspect the implementation and compute a plan. Its effects on the running task must use the same visible-task mouse/keyboard action space available to the evaluated model. No DOM value setters, JavaScript event dispatch, programmatic element clicks, task-state writes, direct submission, URL edits, reloads or navigation may stand in for solving. Browser navigation to initially launch a fresh isolated task is setup, not an oracle action. Clock control, when validating paused runs, belongs to the shared evaluation schedule rather than the solving policy.

Solutions and diagnostics must retain their action records and agree with the live server, direct grader and exported verifier. Success must be achievable without a deliberate failure. Negative/recovery checks are separate attempts. Initial, active, failure and final renders need actual inspection. Model/human calibration and quality promotion remain separate from these automated implementation gates.

## Reproducing a UI check

Use the existing project test dependencies, including its pinned Gym-Anything revision. To run an independent native-input attempt, choose a new output directory:

```bash
python weird_captcha_gym/tools/verify_task_ui.py \
  --environment reflow_vitrine_env --difficulty 3 --interaction full \
  --seed 1 --check solve --out-dir outputs/reflow-recheck
```

Use `--check failure` for a separate rejected/fresh-challenge attempt or `--check clock` for the shared frozen-clock/input protocol. Saved successful UI artifacts can also be checked with `verify_ui_exports_in_browser.py --record <attempt-directory> --out-dir <new-directory>`. Neither tool runs a model or replaces Gym-Anything's benchmark CLI.
