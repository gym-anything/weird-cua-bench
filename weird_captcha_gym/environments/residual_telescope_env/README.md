# The Residual Telescope

Build a luminous source model from three linked image plates: photographed source, assembled model, and signed residual. Component masks unlock in order, and the optical controls continuously rerender the latter two plates.

The baseline is L4 / Full. Its difficulty and interaction assignments are provisional until comparable human and screenshot-driven computer-use-agent measurements are collected. Automated solver runs validate wiring, grading, and mode preservation only.
