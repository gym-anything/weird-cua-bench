# Glyph Market Notebook

Glyph Market Notebook is an original picture-language puzzle grounded in survey record `IND-105` (Chants of Sennaar). A seeded market distributes visual evidence across illustrated stalls. The player inspects the marked contexts, collects each invented glyph, writes a provisional note, and matches the glyphs to novel illustrations on validation pages.

The baseline is difficulty 3 with Full interaction. Simplified interaction preserves the same world and uses a visible select-then-click proxy for the direct drag gesture. The task is static under the settled real-time diagnostic: the market does not autonomously change, and a bounded recent frame window is not needed to choose an action, so it uses a zero-length observation window and one frame.

Automated evidence in `evidence_docs/` is scripted browser evidence only. Human VNC calibration and computer-use-agent results are intentionally recorded as absent until performed.
