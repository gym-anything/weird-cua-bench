# Real-Time Classification of All 750 Configurations

Date: 2026-08-13

This audit applies the settled definition in
`docs/controllability/real-time.md` to every combination of 75 environments,
five difficulties, and two interaction modes. It is a source-based mechanic
classification, not an agent gameplay evaluation.

## Result

- Real-time: 267 / 750
- Not real-time: 483 / 750
- Simplified real-time: 124 / 375
- Full real-time: 143 / 375

## Classification patterns

- 22 environments are real-time at all five difficulties in both interactions.
- 45 environments are not real-time in any difficulty or interaction.
- Reload Interruption, Rotating On-Screen Keyboard, and Temporal Memory /
  First-Change Evidence are real-time only in Full mode.
- Dead Man's Switch is real-time only in Full mode at D2–D5.
- Clockwork Clutch Safe and Specular Lighthouse Relay are real-time at D2–D5
  in both modes.
- Polarized Palimpsest and Marionette Checkpoint are real-time at D3–D5 in
  both modes.

Difficulty usually changes speed, density, tolerance, memory load, or the
number of stages without changing the diagnostic. The five difficulty-sensitive
environments change because their easiest tolerance profiles admit a fixed
observation-free action or schedule that ceases to work at a harder level.

## Configuration-dependent cases

### Clockwork Clutch Safe

D1 has one shaft, an exact release tick in 34–42, and a 30-degree final
tolerance. Releasing at the fixed midpoint, tick 38, stays within tolerance
for every generated release tick, so observation is unnecessary. D2–D5 add
phase-dependent shaft identity or tighter live control that defeats a fixed
schedule.

### Polarized Palimpsest

At D1–D2 there is one echo at a known base. Its maximum displacement is
respectively about 11 and 22 pixels, below the 50- and 40-pixel lock radii.
A fixed base coordinate remains valid over the entire orbit. At D3–D5 the
generated echo assignment and motion exceed that fixed-lock guarantee, so
recent visible motion determines an expiring capture point.

### Dead Man's Switch

In Full D1, the center pointer is always inside the plate: even the maximum
normalized displacement is below the boundary of its hit ellipse. At Full
D2–D5 that guarantee disappears and the pointer must visibly track the moving
plate. Simplified mode automatically tracks it at every difficulty.

### Marionette Checkpoint

At D1, setting the one active string to 64 stays within every generated
moving-ring tolerance. At D2, setting both active strings to 65 does the same.
These are observation-free policies. D3–D5 widen the generated pose range and
narrow the effective ring allowance enough that recent motion is needed to
choose a correction before it loses value.

### Reload Interruption

Full mode grades continuous pointer tracking of the moving overload spark.
Simplified mode explicitly skips the spark-position check and grades only the
fixed hold duration and sample density.

### Rotating On-Screen Keyboard

Full mode must click keys whose screen positions move. Simplified mode sends
the requested stationary physical key, so rotation does not alter the correct
action.

### Specular Lighthouse Relay

At D1 the receiver moves 20–24 pixels and the reflected beam tolerance is 24
pixels, so a beam through the generated receiver base remains valid throughout
the orbit. At D2–D5 the receiver amplitude exceeds beam tolerance, requiring
visible prediction and corrections that lose charge advantage as it moves.

### Temporal Memory / First-Change Evidence

Full mode exposes the lens during the live carrier field, where the required
evidence opportunity moves and disappears. Simplified coordinate controls are
available in review, after live playback, and the reviewed evidence remains
actionable.

## Scope

The table classifies the presence of the real-time component. It does not say
that every step of a `Yes` task is time-sensitive, nor that a `No` task lacks
animation, timers, temporal memory, duration requirements, or physics. The
three clauses must be witnessed by the same visible, autonomously changing,
expiring control opportunity.
